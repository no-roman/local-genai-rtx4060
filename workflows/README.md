# Рабочие процессы ComfyUI

Сюда — `.json`, сохранённые из ComfyUI (Workflow → Export).
Имя файла: `задача-модель-разрешение.json`, например
`картинка-sdxl-1024.json`, `видео-wan-480p.json`.

Для автоматизации рядом — тот же процесс в API-формате (Workflow →
Export (API)) с окончанием `.api.json`; изменяемым узлам — заголовки
(`ВИД`, `ЗАПРОС`, `SEED`). Подробно — [docs/05-автоматизация.md](../docs/05-автоматизация.md).

Рядом с каждым — строка в таблице ниже: время и видеопамять на RTX 4060.
