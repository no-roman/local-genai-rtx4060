# Локальная генерация изображений и видео на RTX 4060

Цель — рабочая связка на своём компьютере, без облачных сервисов:
- **изображения** — по тексту, по эскизу, по глубине и контурам своих моделей;
- **короткое видео** — по тексту и по одной картинке;
- **для конфигуратора NODE** — фоны, отделки, варианты фасадов;
- **и не только** — любые свои задачи.

## Железо и главное ограничение

- Видеокарта — **RTX 4060, 8 ГБ видеопамяти**. От этого зависит выбор моделей:
  - большие модели — только в сжатом виде (GGUF Q4–Q5, FP8/NF4);
  - видео — короткие ролики, 480p–720p, несколько секунд;
  - при нехватке видеопамяти часть модели уходит в оперативную память:
    это работает, но медленно.
- Оперативной памяти желательно 32 ГБ, диск — SSD, под модели 100–200 ГБ.

## Статусы у цифр

Как в проекте NODE: **«проверено»** — замерено на этой карте,
**«получено»** — взято из документации или от авторов модели,
