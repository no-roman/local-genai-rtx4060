# Для конфигуратора NODE

Конфигуратор — `no-roman/house-configurator`. Его правила действуют
и здесь.

## Нельзя

- Рендеры, фото и адреса объектов заказчиков — ни как исходник,
  ни как образец стиля, ни для дообучения.
- Персональные данные.
- Выдавать сгенерированную картинку за фото построенного дома.
  Подпись — «иллюстрация».

## Можно и полезно

| Задача | Как | Исходник |
|---|---|---|
| Вид дома в окружении | ControlNet глубина/контуры по виду из Revit, окружение — текстом | свои модели серии NODE |
| Варианты отделки фасада | тот же вид, меняется запрос: доска, штукатурка, фиброцемент | свои модели |
| Образцы материалов для выбора | картинка материала крупно, бесшовная текстура | текст запроса |
| Сезоны и время суток | одна основа, разные запросы | свои модели |
| Короткий облёт | картинка → видео (LTX / Wan I2V), 3–5 с | сгенерированная картинка |

## Порядок

1. Экспорт вида из Revit — без подписей, адресов и привязки к участку.
2. Препроцессор глубины или контуров в ComfyUI.
3. Генерация по запросу; отбор.
4. Готовое — в конфигуратор отдельной задачей в его репозитории,
   с подписью «иллюстрация».

Модели и файлы владельца (`E:\project\`, `E:\NODE\`) — только читать
и экспортировать виды, не пересохранять.
