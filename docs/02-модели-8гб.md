Для архитектуры (вид из Revit → фото, варианты отделки) — отдельный
обзор: [04-архитектура.md](04-архитектура.md). Коротко: Z-Image Turbo
с ControlNet Union и FLUX.2 [klein] 4B — новые, быстрые, Apache 2.0.

## Управление по своей картинке (ControlNet)

- **Глубина** (depth) — форма дома из своего вида Revit, материал и
  окружение — по тексту.
- **Контуры** (canny / lineart) — точные линии фасада.
- Для SDXL — ControlNet Union (одна модель на несколько режимов).
- Для Flux — Flux ControlNet / Flux Depth/Canny (проверить, влезает ли).
- Для Z-Image Turbo — Fun ControlNet Union (canny, HED, depth, MLSD).

(картинка → видео, быстро). 14B — только когда нужно качество
и есть время ждать.

## Ускорители (после первых замеров)

- Дистиллированные версии и LoRA на малое число шагов (4–8 шагов вместо 20–30).
- TeaCache / кэш шагов для видео.
- SageAttention — ускорение внимания; ставится отдельно, на Windows
  бывает капризно.
