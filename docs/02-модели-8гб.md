# Модели, которые помещаются в 8 ГБ

Все цифры — **«оценка»**, пока не замерены на этой карте.
Перед скачиванием — проверить лицензию на странице модели.

## Изображения

| Модель | В каком виде | Разрешение | Скорость на 4060 | Лицензия | Статус |
|---|---|---|---|---|---|
| SDXL (и дообученные на её основе) | FP16 `.safetensors`, ~7 ГБ | 1024×1024 | ~10–20 с на картинку | открытая (CreativeML OpenRAIL++) | оценка |
| Flux.1 [schnell] | GGUF Q4–Q5 или FP8 | до 1024×1024 | ~20–40 с | Apache 2.0 | оценка |
| Flux.1 [dev] | GGUF Q4–Q5 | до 1024×1024 | ~1–2 мин | некоммерческая | оценка |
| SD 3.5 Medium | FP16 / GGUF | 1024×1024 | ~30–60 с | Stability Community | оценка |

С чего начать: **SDXL** — быстро, много дообученных версий под
архитектуру и интерьеры, много ControlNet. Потом **Flux schnell** в GGUF —
лучше понимает текст запроса.

## Управление по своей картинке (ControlNet)

- **Глубина** (depth) — форма дома из своего вида Revit, материал и
  окружение — по тексту.
- **Контуры** (canny / lineart) — точные линии фасада.
- Для SDXL — ControlNet Union (одна модель на несколько режимов).
- Для Flux — Flux ControlNet / Flux Depth/Canny (проверить, влезает ли).

## Видео

| Модель | В каком виде | Ролик | Время на 4060 | Лицензия | Статус |
|---|---|---|---|---|---|
| Wan 2.x T2V/I2V 1.3B | FP16 | 480p, ~3–5 с | ~5–10 мин | Apache 2.0 | оценка |
| Wan 2.x 14B | GGUF Q3–Q4 + выгрузка в ОЗУ | 480p, ~3 с | ~20–40 мин | Apache 2.0 | оценка |
| LTX-Video (малые версии, distilled) | FP8 / GGUF | 512–768p, ~3–5 с | ~1–3 мин | открытая, условия на странице | оценка |

С чего начать: **Wan 1.3B** (текст → видео) и **LTX-Video distilled**
(картинка → видео, быстро). 14B — только когда нужно качество
и есть время ждать.

## Ускорители (после первых замеров)

- Дистиллированные версии и LoRA на малое число шагов (4–8 шагов вместо 20–30).
- TeaCache / кэш шагов для видео.
- SageAttention — ускорение внимания; ставится отдельно, на Windows
  бывает капризно.
