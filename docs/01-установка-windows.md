# Установка на Windows

## 1. Драйвер

- Свежий драйвер NVIDIA (Studio или Game Ready) с сайта NVIDIA.
- Проверка: `nvidia-smi` в командной строке — видна RTX 4060 и 8 ГБ.

## 2. ComfyUI

Основной инструмент: узлы вместо кнопок, но лучше всех экономит
видеопамять и первым получает поддержку новых моделей.

Два пути, выбрать один:

- **ComfyUI Desktop** — установщик с comfy.org, всё ставит сам.
  Проще всего для начала.
- **Портативная сборка** — архив `ComfyUI_windows_portable` со страницы
  релизов на GitHub (comfyanonymous/ComfyUI). Распаковать на SSD,
  запуск — `run_nvidia_gpu.bat`.

Интерфейс открывается в браузере: `http://127.0.0.1:8188`.
Наружу не открывать (не запускать с `--listen`), если не нужно.

## 3. Менеджер узлов

ComfyUI-Manager — ставит недостающие узлы и модели из интерфейса.
В Desktop уже есть; в портативной — по инструкции на его странице.

Нужные дополнения (через менеджер):
- **ComfyUI-GGUF** — загрузка сжатых моделей `.gguf` (Flux, Wan);
- **ComfyUI-VideoHelperSuite** — сборка кадров в видео;
- **ControlNet-препроцессоры** (comfyui_controlnet_aux) — глубина,
  контуры, линии по своей картинке.

## 4. Папки моделей

Внутри `ComfyUI/models/`:

| Папка | Что класть |
|---|---|
| `checkpoints/` | цельные модели SDXL (`.safetensors`) |
| `diffusion_models/` или `unet/` | основа Flux, Wan, LTX (`.safetensors`, `.gguf`) |
| `text_encoders/` или `clip/` | текстовые кодировщики (T5, CLIP, UMT5) |
| `vae/` | VAE |
| `loras/` | LoRA — дообучение под стиль |
| `controlnet/` | ControlNet |

Если моделей много и диск другой — `extra_model_paths.yaml`
(пример лежит в папке ComfyUI).

## 5. Если не хватает видеопамяти

По порядку:
1. Взять более сжатую версию модели (Q5 → Q4, FP16 → FP8).
2. Уменьшить разрешение или число кадров.
3. Текстовый кодировщик — тоже в сжатом виде (T5 FP8 / GGUF).
4. Флаг запуска `--lowvram` (медленнее, но влезает).
5. Закрыть браузер с тяжёлыми вкладками и другие программы на GPU.

## 6. Что записать после установки

В HANDOFF.md: версия драйвера, версия ComfyUI, объём оперативной памяти,
диск под модели.
