# Автоматизация генераций

Условия владельца: Windows, **n8n установлен без Docker**, Node.js есть
(на нём работает n8n), **Python нет**. Всё ниже — без Python и без облака.

## Что автоматизировать

| Задача | Пример |
|---|---|
| **Серия вариантов** — главное | вид 01 × {доска, штукатурка, фиброцемент} × {лето, зима} = 6 картинок одним запуском |
| Ночная очередь | тяжёлые правки Qwen-Image-Edit и видео Wan — ставить на ночь |
| Папка «входящие» | положил экспорт вида из Revit — через минуту готовы варианты |
| Отбор в два шага | быстрые черновики → отобранные → увеличение до 2–4K |

## Три способа — от простого к сложному

| Способ | Что нужно | Когда |
|---|---|---|
| **1. Внутри ComfyUI** | дополнение Inspire Pack | несколько запросов к одному виду, без имён файлов и отчёта |
| **2. Скрипт `automation/series.mjs`** — рекомендую | только Node.js (уже есть) | серии по таблице: вид × отделка × сезон, свои имена файлов, время каждой картинки |
| **3. n8n** | n8n (уже есть) | нужен запуск по расписанию, по папке, уведомления |

### 1. Внутри ComfyUI

Дополнение **ComfyUI Inspire Pack** (ставится через менеджер):
- `Load Prompts From File` — запросы из текстового файла, по одному на задание;
- `Load Image List From Dir` — все картинки из папки по очереди.

Плюс — ничего, кроме ComfyUI. Минус — сочетания «вид × отделка» и имена
файлов собирать неудобно, отчёта о времени нет.

### 2. Скрипт series.mjs — одна строка таблицы = одна картинка

Таблицу вариантов удобно вести в Excel, запуск — одна команда.

**Подготовка процесса в ComfyUI (один раз):**
1. Собрать и проверить процесс руками.
2. Узлам, которые будут меняться, дать **заголовки** (правый клик →
   Title), например: `ВИД` (Load Image), `ЗАПРОС` (текст запроса),
   `SEED` (KSampler). Заголовки не должны повторяться.
3. Сохранить в **API-формате**: меню Workflow → Export (API).
   Имя — как у обычного, с `.api.json`: `workflows/фасад-zimage-1024.api.json`.

**Таблица** — пример: [automation/варианты-пример.csv](../automation/варианты-пример.csv).

```
имя;ВИД.image;ЗАПРОС.text;SEED.seed
вид01_доска_лето;input/вид-01.png;"modern house, larch plank facade, summer, ...";42
вид01_штукатурка_лето;input/вид-01.png;"modern house, white plaster facade, summer, ...";42
```

- Колонка — `ЗАГОЛОВОК УЗЛА.поле`. Поля видны в API-файле у узла в `inputs`
  (у KSampler — `seed`, `steps`, `cfg`; у текста — `text`; у Load Image — `image`).
- `имя` — имя файла результата.
- Путь к картинке (`input/вид-01.png`) скрипт сам загрузит в ComfyUI.
- Excel: «Сохранить как → CSV UTF-8». Обычный CSV из Excel — в другой
  кодировке, русские буквы испортятся.
- Одинаковый `SEED` во всех строках — варианты сопоставимы между собой.

**Запуск** (ComfyUI должен быть открыт), в папке репозитория:

```
node automation/series.mjs --workflow workflows/фасад-zimage-1024.api.json --csv варианты.csv --out output/серия-01
```

- `--dry` — проверить таблицу и заголовки, ничего не генерируя.
  Скрипт в любом случае проверяет все строки до начала серии.
- `--server` — адрес ComfyUI, по умолчанию `http://127.0.0.1:8188`.
- `--timeout` — предел на одну картинку в минутах, по умолчанию 60.

**Результат:** картинки с именами из таблицы и `отчёт.csv` — сколько секунд
заняла каждая. Время из отчёта сразу идёт в замеры со статусом «проверено».

Задания идут строго по одному: карта одна, параллельный запуск только
замедлит. Ошибка в одной строке не останавливает серию — она попадёт в отчёт.

Проверено на заглушке сервера ComfyUI (загрузка вида, подстановка,
ожидание, скачивание, ошибки узлов, недоступный сервер). С настоящим
ComfyUI ещё не запускалось.

### 3. n8n — когда нужен запуск «сам по себе»

n8n стоит в Windows без Docker, поэтому ComfyUI доступен ему по
`http://127.0.0.1:8188` — запускать ComfyUI с `--listen` **не нужно**
и не стоит.

Два пути:

**а) n8n запускает скрипт** — проще всего.
`Schedule Trigger` (например, 01:00) → `Execute Command`:
`node D:\путь\к\репозиторию\automation\series.mjs --workflow ... --csv ...`.
В n8n 2.x узлы `Execute Command` и `Local File Trigger` **выключены
по умолчанию** — включить переменной окружения `NODES_EXCLUDE="[]"`
перед запуском n8n.

**б) n8n сам говорит с ComfyUI** — через узлы HTTP Request:

| Шаг | Узел n8n | Запрос к ComfyUI |
|---|---|---|
| 1 | Read/Write Files from Disk | прочитать вид из Revit |
| 2 | HTTP Request | `POST /upload/image` (form-data, поле `image`) → имя файла |
| 3 | Code | подставить значения в API-файл процесса по заголовкам узлов |
| 4 | HTTP Request | `POST /prompt` с телом `{"prompt": …}` → `prompt_id` |
| 5 | Wait + HTTP Request, в цикле | `GET /history/{prompt_id}` — пока не появится `outputs` |
| 6 | HTTP Request (ответ — файл) | `GET /view?filename=…&subfolder=…&type=output` |
| 7 | Read/Write Files from Disk | сохранить картинку |

Для шага 3 подходит функция `applyRow` из `automation/series.mjs` —
её тело можно перенести в узел Code.

В n8n 2.x узлы работы с файлами по умолчанию видят только папку
`~/.n8n-files` (`C:\Users\<имя>\.n8n-files`); другую папку — переменной
`N8N_RESTRICT_FILE_ACCESS_TO`.

Готовые узлы сообщества вместо HTTP Request:
[n8n-nodes-comfyui](https://github.com/mason276752/n8n-nodes-comfyui)
(ждёт результат, предел 30 мин) и
[n8n-nodes-comfyui-toolkit](https://community.n8n.io/t/n8n-nodes-comfyui-toolkit-non-blocking-comfyui-nodes-with-session-tracking/281174)
(март 2026: отправил — ушёл, результат забирает отдельным шагом).
Это чужой код внутри n8n с доступом к его учётным данным — ставить,
только если HTTP Request неудобен.

## Правила

- **ComfyUI — только на 127.0.0.1.** Без `--listen`, порт 8188 наружу не открывать.
- **Облачные узлы n8n** (Telegram, Google Таблицы, почта) выносят картинку
  с компьютера. Можно только свои виды NODE, без адресов; ключи —
  в учётных данных n8n, не в git.
- **Метаданные.** ComfyUI записывает в PNG весь процесс и запрос,
  в том числе имена файлов и папок. Перед выкладкой в конфигуратор —
  сохранять без метаданных (пересохранить в JPEG/WebP).
- **Смена тяжёлых моделей** в одной серии — между ними `POST /free`
  (выгрузить модели), иначе память забьётся.
- **В git** — API-файлы процессов, скрипт, пример таблицы. Картинки,
  отчёты, папки `input/` и `output/` — нет (см. `.gitignore`).
