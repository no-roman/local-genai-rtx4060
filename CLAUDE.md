# Локальная генерация изображений и видео на RTX 4060

- **Цель.** Рабочая связка на компьютере владельца: картинки и короткое
  видео локально, без облачных сервисов. Одна из задач — материалы для
  конфигуратора NODE (`no-roman/house-configurator`), но не только.
- **Карта — RTX 4060, 8 ГБ.** Любой совет проверять на этот предел:
  модель, сжатие, разрешение, длина ролика.
- **Статусы у цифр:** «проверено» (замерено на этой карте),
  «получено» (из документации), «оценка».
- **В git не класть:** веса моделей, результаты генерации, окружения,
  ключи. Список — `.gitignore`.
- **Для конфигуратора NODE** — правила его репозитория:
  - рендеры, фото и адреса объектов заказчиков не использовать —
    ни как исходник, ни как образец;
  - исходники — только свои модели серии NODE и общедоступные материалы;
  - персональных данных нет.
- **Лицензии моделей** — указывать в `docs/02-модели-8гб.md`; для
  коммерческого показа брать только модели с разрешающей лицензией.
- **После этапа** — дописать HANDOFF.md, ничего не удаляя.
